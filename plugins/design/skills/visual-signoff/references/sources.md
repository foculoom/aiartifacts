# Sources

- W3C, *Web Content Accessibility Guidelines (WCAG) 2.2*, https://www.w3.org/TR/WCAG22/ (verified 2026-11-26).
- W3C WAI, "Understanding SC 1.4.3 Contrast (Minimum)," https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum (verified 2026-11-26). Ordinary text 4.5:1; large text 3:1.
- W3C WAI, "Understanding SC 1.4.11 Non-text Contrast," https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast (verified 2026-11-26). UI components, states, and focus indicators 3:1 against adjacent colours.
- W3C WAI, "Understanding SC 2.4.13 Focus Appearance," https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance (verified 2026-11-26). Visible focus with a 3:1 change of contrast.

These documents define the contrast thresholds this skill measures. They do not certify a page by themselves, and a recorded ratio is only as good as the colours and states actually sampled.
