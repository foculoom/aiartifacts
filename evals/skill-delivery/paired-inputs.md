# Input-only paired preparations

Each fenced block is supplied unchanged to the baseline and helper sessions.
Fixtures and tools are prepared according to README.md, which is withheld.

## T1

```text
Prepare source/editorial-writing so a reviewer can decide whether to share it
through skills.sh. Preserve the canonical instructions and declared license.
Create a self-contained candidate package under output/, a file/hash inventory,
dependency/provenance notes and a concise validation/remaining-work report.
Use the existing authoring workflow and tools available here. Do not install
dependencies, submit, publish, or alter source/.
```

## T2

```text
Prepare a review packet for contributing source/editorial-writing to
awesome-copilot. Inspect its current licensing and the supplied official
contribution requirements. Include the intended files, validation evidence,
draft submission text and any unresolved decisions under output/. You may
prepare files but have no authority to change licensing, submit a pull request
or publish. Do not install dependencies or alter source/.
```

## T3

```text
Prepare an updated distribution candidate for source/new/editorial-writing.
Compare it with source/old/editorial-writing and the supplied old archive.
Return a fresh self-contained package, exact file/hash inventory, change and
provenance notes, and a validation/remaining-work report under output/.
Only skill files cleared for distribution belong in the package. Do not
publish, install dependencies, modify source/, or modify the old archive.
```
