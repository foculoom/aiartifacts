## Reproduce local checks without installation

From the supplied workspace root:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 existing-authoring/scripts/quick_validate.py output/candidate/skills/editorial-writing
mkdir -p output/validation/tmp
TMPDIR="$PWD/output/validation/tmp" PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s output/candidate/skills/editorial-writing/tests -v
TMPDIR="$PWD/output/validation/tmp" PYTHONDONTWRITEBYTECODE=1 python3.12 -m unittest discover -s output/candidate/skills/editorial-writing/tests -v
PYTHONDONTWRITEBYTECODE=1 python3 output/candidate/skills/editorial-writing/scripts/prose_lint.py output/candidate/skills/editorial-writing --format json
```

Use an absolute physical workspace path; symlink ancestors are rejected by the helper. Test temp files are disposable and were removed after this run. The standalone candidate's checker and tests work without the authoring toolkit; only the first command needs that separate toolkit and PyYAML. To verify this delivery's checksums on macOS, run `shasum -a 256 -c SHA256SUMS` from `output/`.
