# Codex paired preparation receipts — 30 October 2026

These six arms compare the same supplied inputs and tools, with the helper
installed only in the helper projects. They are directional observations:
the serving model and complete initial exec context were not exposed, and a
strict no-helper baseline was not independently proven. The predeclared
usefulness gate is therefore **unmeasured**, regardless of correction counts.
See [the held-out criteria](../../criteria.md) and the [independent grader](grader.md)
for quality and safety judgments. Final task quality passes after two bounded
corrections. Baseline/helper correction counts are 1/0 for T1, 0/0 for T2 and
0/1 for T3: the helper improved one pair, short of the required two.

The first six attempts encountered the workspace spend cap before task work;
they are retained as provider/resource failures, not arm performance. After the
user restored usage, fresh `-r2` attempts used equal 300-second deadlines and
unchanged task prompts/fixtures. Within each pair the order was baseline then
helper for T1/T3 and helper then baseline for T2; pairs ran concurrently.
Codex CLI `0.166.0-alpha.5.1` used the existing ChatGPT subscription; API keys,
provider overrides and parent session variables were omitted. No account or
user configuration was changed.

[Installed-helper hashes](installed-helper-files.json), per-case source records
and input inventories identify all staged bytes. The baseline projects contain
no candidate helper folder or script. Both arms received the same already
available authoring workflow and pinned official-source snapshots. The helper
was actually installed by reviewed skills CLI 1.7.4 with project-local copy
placement and telemetry disabled. The baseline's lack of staged helper bytes
does not prove absence of all hidden host instructions or access.

T1-baseline-r2-c1 is a separate reviewer-requested finishing trial with the
original baseline files/output and the exact narrow correction prompt. It added
concrete unexecuted skills.sh commands and updated report checksums. It received
no helper resources or held-out criteria. T3-helper-r2-c1 is a separate
120-second-budget correction that removes an unsupported claim of human review,
leaves that review pending and updates report checksums. Its package is unchanged.
Original outputs remain unchanged in the initial result folders. Both corrections
are independently verified; repeated defects are counted once.

Every artifact map binds original generated hashes to complete public text
snapshots or unchanged reviewed ZIPs. Non-text, non-ZIP scratch binaries are
withheld; entries retain original hash/size and the reason. Path/session
redactions are labeled and do not rewrite candidate package contents. The
[upstream notices](../upstream-notices/README.md) attribute retained external
code/prose. The evidence inventory includes this README and finalized grading
and excludes only itself. No submission, publication, listing or new customer
acquisition occurred in these trials.
