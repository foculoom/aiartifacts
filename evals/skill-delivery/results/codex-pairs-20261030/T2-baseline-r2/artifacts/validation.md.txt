The default temporary directory resolves through macOS `/var`, a symlink to `/private/var`. `_safe_absolute` deliberately rejects any symlinked ancestor, so temporary fixtures cannot be read through that alias. Setting only the test process's `TMPDIR` to the resolved `output/test-tmp` path removes the alias and all 27 tests pass. This isolates an environment-dependent path limitation; it does not fix it. The failed default run is retained and remains an unresolved portability decision. Tests that deliberately exercise input symlinks still execute and pass with the canonical temporary root.

The suite checks Markdown masking and source positions, exact warning boundaries, repetition across documents, opt-in heading checks, JSON/CLI behavior, input errors, symlink handling and no-rewrite behavior. It does not verify editorial quality, factual correctness, actual reader feedback, Copilot skill invocation or installation. A zero-finding advisory lint run has no such implication.

The complete upstream checkout/dependencies and required hosts are absent; no dependencies were installed.
