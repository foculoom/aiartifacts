# Keeping a second copy

In today's fast-paced world, a backup is a second copy of a file. Backups are important. You should back up important files. You should remember to create backups because backups are important.

Suppose the only copy of your family photos is on a laptop. If its drive fails, you may lose those photos. Put a second copy on another device. After copying, open one photo from the second device to check that it is readable. A copy you have never tried to open may not help when you need it.

A simple routine can help. Pick a regular time to copy new photos. Keep the second device separate from the laptop when you are not using it. If you delete a photo accidentally, check the second copy before replacing it. A backup is useful only when you know where it is and can open it.

This introduction does not cover every storage option. You can start with one folder of photos and practice copying it. Write down where you put the copy. Then return to the folder later and open a photo without using the original device. Doing this small check now can show whether your instructions are clear enough to follow later.
