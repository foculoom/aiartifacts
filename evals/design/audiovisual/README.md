# Audiovisual evidence evaluations

Use the existing experience-review skill with only [inputs.md](inputs.md) in a
fresh evaluator session. Keep [assessment.md](assessment.md) withheld until the
complete answer is fixed. Retain input and skill identities, actual tools,
reviewer type, complete answer and limitations. The cases are original synthetic
text, with no private product material or real participant records.

The intended task is selecting relevant media evidence and calibrating claims
for apps and games, including capture failure and missing review capability.
These cases accept only bounded guidance decisions. They do not exercise actual
image/audio perception, render interaction, native output or installed routing.
Any claim about those behaviors requires the actual artifact, relevant authorized
capability and the existing production-experience acceptance record.

See the [November 3 record](results-20261103/README.md) for exact inputs, output,
assessment and remaining evidence. Package release and consumer adoption remain
separate from source integration.
